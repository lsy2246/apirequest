# 历史记录、复制反馈与界面整理

正式版本：`v0.1.2`。

## 修改结果

- 历史记录默认配置统一使用 `ENABLE`。读取旧数据库时将 `true/false` 解释为 `ENABLE/DISABLE`，保留明确关闭的选择，不批量重写配置或历史数据。
- 历史页分别显示加载中、加载失败、关闭、空记录和搜索无结果。查询失败保留已有数据并提供重试，移除联系组织管理员的指引。
- 历史页只保留“记录历史”开关，控制当前设备新执行的 HTTP 和 GraphQL 请求及其完整响应；暂停后保留已有记录，恢复后只记录新请求。该偏好保存在设备设置中，不写入共享设置，读取共享设置时也不覆盖本机选择。
- 旧的服务端关闭配置可通过历史页显式启用。恢复接口沿用本地工作台所有者鉴权，并通知其他客户端重新读取状态。
- 历史记录只保留一个主开关：开启即完整保存请求和响应，关闭则停止新增。移除历史页及请求设置中的独立响应保存开关；兼容旧的响应保存关闭配置，在开启记录或首次归档前自动启用完整保存。清理设置保留。
- 网页与桌面共用异步剪贴板方法。原生复制等待 IPC 结果，网页等待 Clipboard API，兼容复制检查返回值并恢复焦点；失败向调用者传递错误。
- MCP、抓包、Mock、文档、响应正文和响应头、代码生成、GraphQL、WebSocket 日志、控制台、AI 消息、访问令牌等入口统一使用复制反馈。完成写入后才显示成功或切换图标，失败显示可重试提示。MCP 复制期间禁用按钮并显示处理中状态。
- MCP 配置复制按钮增加边框、背景、复制图标和最小高度，复制成功后切换为勾选图标和成功文案。
- 本地按钮封装统一使用文案或显式标签作为可访问名称，保留导航链接语义、显式提交行为和上游样式，处理中禁用重复操作。
- MCP 配置格式、Mock 高级匹配条件和设置页的命名风格统一接入工作台下拉框。历史页复用工作台的加载、错误和空状态组件。
- 修复请求取消、未知超时阶段、复制失败、OAuth 刷新失败、控制台空状态及集合导入等翻译引用；PEM/PFX 使用固定格式名称。中英文展示名称统一为 API Request。
- 删除各语言中已无引用的组织管理员历史提示、官方代理托管说明和旧实验性沙盒说明等翻译键。
- 私有 Mock 鉴权仍使用访问令牌，保留相应接口和页面，在网页设置中增加入口并采用工作台布局。桌面构建继续排除该网页功能。
- 保留有效的数据格式兼容、上游依赖包身份和第三方来源声明。

## 数据与部署

本次不修改数据库结构，不需要新增 Prisma 迁移。服务端读取兼容旧开关值；手动启用时仅更新历史记录开关，不删除历史数据。网页和后端应使用同一批代码。桌面构建通过编译期开关排除历史页重试所依赖的网页 GraphQL 模块。

## 验证

- 单开关调整：4 个测试文件、15 项测试通过，覆盖完整响应字节和响应头、旧配置恢复、导入旧配置后的再次记录、桌面归档准备、失败重试及暂停保留。网页构建通过，本地历史页确认仅保留“记录历史”开关。
- 前端定向回归：19 个测试文件、141 项测试，覆盖复制延迟与拒绝、桌面 IPC、兼容复制失败、MCP 页面反馈、按钮名称与提交语义、历史查询重试、旧关闭配置恢复、设备暂停与恢复、设备偏好隔离及既有持久化、Mock、文档和请求执行功能。
- 后端：2 个测试文件、14 项测试，覆盖四种历史开关值、显式恢复、所有者校验与保存失败。
- 网页生产构建通过；桌面前端生产构建在单开关及复制按钮样式的最终调整前通过，最终调整未重新构建桌面前端。后端 TypeScript 检查通过。
- 浏览器验收使用独立临时页面、模拟管理 API 和剪贴板，检查历史开关刷新保持、错误重试、显式恢复、MCP 复制成功与失败、下拉选择、Mock 地址复制、窄屏布局和设置入口。不连接真实业务数据，不改动系统剪贴板。
- 修改文件 ESLint 检查无错误；遗留代码和测试桩仍有警告。中英文翻译键和占位参数一致，`git diff --check` 通过。

完整前端类型检查仍有既有的生成接口、公共类型导出及页面诊断，不能视为全项目类型检查通过。新增按钮封装单独通过严格类型检查。本轮未运行桌面安装包或真实操作系统剪贴板验收。
