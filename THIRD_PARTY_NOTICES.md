# Third-party notices

API Request derives from the Hoppscotch codebase. Original project: https://github.com/hoppscotch/hoppscotch. Upstream contributors include the Hoppscotch contributors.

The application uses upstream packages through local dependency aliases, including `@hoppscotch/ui`, `@hoppscotch/httpsnippet`, and the appload and relay plugins. Their package identities, author notices and license information remain with their distributions and lockfiles. These dependencies are not API Request support or cloud service endpoints.
